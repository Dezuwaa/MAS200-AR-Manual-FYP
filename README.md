## 📱 How to Install and Run the AR App

To test this Augmented Reality application on your Android device, follow these steps:

### Prerequisites
* An Android device that supports **ARCore / Google Play Services for AR**.
* Android OS 7.0 (API Level 24) or higher.

### Installation Steps
1. **Download the App:** Open this GitHub repository on your Android phone's browser, navigate to the **Releases** tab, and download the latest `.apk` file.
2. **Allow Unknown Sources:** If prompted by your browser or file manager, enable *“Allow installation from unknown sources”* in your device settings.
3. **Install:** Open the downloaded `.apk` file and tap **Install**.
4. **Permissions:** When launching the app for the first time, make sure to accept the **Camera Permission**, as it is strictly required for the AR Tracking functionality to work.
